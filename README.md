# Jiaxing Li Personal Page

Personal academic homepage for Jiaxing (Marsh) Li, built with the AcademicPages Jekyll template.

## Local Preview

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

The site is configured as a GitHub Pages project site at:

```text
https://jiaxingli-sfu.github.io/JiaxingLi_Personal_Page/
```

## Structure

- `_pages/about.md`: homepage content, including About Me, News, and Selected Publications.
- `_pages/publications.md`: full publication list.
- `_publications/`: individual publication detail pages.
- `_includes/home/`: homepage content sections.
- `resources/`: publication images and slides.
- `images/`: profile image and site icons.
